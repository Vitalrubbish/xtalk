# runtime_adapter.py

## 功能与类

DuplexRuntimeAdapter是唯一在线协议执行器，串行处理micro-turn，保存user增量文本、原始assistant token IDs、回复身份与独立的已听事实。运行时默认按session_id启用KV复用，显式诊断配置可关闭；不新增推理仲裁或播放所有者。

## 核心方法

_handle_micro_turn按request_id提交历史并消费完整生成流，拒绝重复请求和过期前缀；_append_user处理增量与ASR改写，_request_history保留原始IDs。_apply_control依次执行控制标记，finish talking打开speaking窗口，talking/interruption仅在窗口打开时停止未播输出；用户backchannel与普通续写保留原流。

_append_answer跨micro-turn复用response_id与TTS会话，向现有播放链路增量追加正文，只对合成副本去句点；记录首正文/请求/回复关联。_finish_answer在thinking时flush，_stop_answer停止未播内容，_heard保存单调增长的播放确认。shutdown先取消生成，再停输出、释放本会话服务缓存。

## 边界

ASR final不独立触发模型，推理期间到达的ASR在下一拍消费。允许模型thinking后在相同前缀再次回答，完整保存历史；重复正文由质量评测判断。系统backchannel模块仍未启用，现有user backchannel标记继续描述用户行为。
