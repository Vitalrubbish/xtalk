# 连续流式 ASR 客户端测试

检查 80 ms 块大小、暂停与真正结束的区分，以及服务文本直接交付，不施加前缀过滤。

测试使用延迟结果假 HTTP、真实 `ASRManager` 和 `MicroTurnAssembler` 验证：上一拍之后才 emit 的文本即使没有新音频也进入下一拍；首次空拍与重复文本产生空 user 内容；每拍只读取一次，拍间不自动读取；短音频块保留，读取不触发 EOF；取消和关闭后不发布旧结果或重建会话。

`acoustic_vad_enabled=false` 时会话由连续 ASR 接管，服务禁用声学 VAD 检测、声学开始/结束控制及 pause/resume 调度。浏览器在握手后创建关闭 VAD 的输入设备，旧客户端声学信号在网关被忽略。静音和播放期间输入保持连续，每个 micro-turn 读取当前转写但不关闭解码器。
